# Personal Portfolio Website

This is a responsive personal portfolio website built using HTML, CSS, and JavaScript. The website is designed to showcase my profile, skills, education, and other details in a clean and structured format.

## 🚀 Features
- Responsive design for different screen sizes
- Clean and professional UI
- Sidebar navigation for easy access to sections
- Sections included: About, Education, Skills, Interests
- Social media links integration

## 🛠️ Tech Stack
- HTML
- CSS (Flexbox, Grid)
- JavaScript
- Bootstrap

## 📌 Purpose
This project was created as a practice task to strengthen my frontend development skills and understand layout structuring, styling, and responsiveness.
